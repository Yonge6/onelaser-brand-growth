# Websites project links design

## Direction

Keep the existing compact portfolio grid and turn chapter 02 into a website archive rather than a generic digital-project collection. The section remains four columns on wide screens, two on tablets, and one on mobile. Its headline explains that several independent websites perform distinct jobs while contributing to one connected OneLaser brand and growth journey.

## Card actions

Each card keeps an image as its primary preview link and exposes explicit text actions in the footer. Most cards have one `Open website` action. OneLaser Homepage V3 is the sole two-action exception: `Design preview` opens the GitHub Pages prototype and `Live website` opens the public OneLaser website. The links are siblings rather than nested anchors so keyboard and screen-reader behavior stays valid.

## Additions and verification

Hydra Gen2 Listing and OneLaser Accessories join the same data-driven collection with source imagery from their live sites and bilingual outcome-led copy. Verification covers generated project counts, all requested link destinations, desktop/tablet/mobile grid behavior, keyboard-accessible actions, successful production build and Sites tests, and live-domain readback after deployment.
